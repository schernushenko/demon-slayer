# Кимэцу — фан-сообщество Demon Slayer

Адаптивная заготовка фан-сайта на React, TypeScript и Vite. Включает главную страницу с баннером и локальными иллюстрациями из `public/demon-slayer.jpg`, каталог персонажей с локальными описаниями и модальными подробностями, викторину «Кто ты из Клинка?», раздел о мире и таймлайн сюжетных арок с анимацией GSAP ScrollTrigger. Каталог не обращается к внешнему API. Цвет акцента карточек соответствует стилю дыхания персонажа. Декоративные элементы и типографика созданы с помощью CSS.

## Запуск

```bash
npm install
npm run dev
```

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

Фанатский проект, не связанный с авторами и правообладателями оригинального произведения.
