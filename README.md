# Кимэцу — фан-сообщество Demon Slayer

Адаптивная заготовка фан-сайта на React, TypeScript и Vite. Включает главную страницу с баннером и локальными иллюстрациями из `public/demon-slayer.jpg`, каталог персонажей с локальными описаниями и модальными подробностями, викторину «Кто ты из Клинка?», раздел о мире и таймлайн сюжетных арок с анимацией GSAP ScrollTrigger. Каталог не обращается к внешнему API. Цвет акцента карточек соответствует стилю дыхания персонажа. Декоративные элементы и типографика созданы с помощью CSS.

## Запуск

```bash
npm install
npm run dev
```

## Администрирование

Админ-панель не имеет ссылки в публичном интерфейсе и доступна по адресу `/admin`. Данные защищены серверной проверкой логина и пароля; скрытый адрес сам по себе не является защитой.

При первом запуске задайте логин и пароль:

```bash
npm run admin:setup
```

Пароль вводится скрыто и должен содержать не менее 12 символов. Команда сохраняет scrypt-хеш в `admin.config.json`; файл исключён из Git. Пароль также можно задать напрямую в этом JSON через поле `password` (удалив `passwordHash`), но тогда он будет храниться в файле открытым текстом — не добавляйте его в Git и ограничьте доступ к файлу. Чтобы сменить пароль безопасно, повторно запустите команду настройки. Текущие сессии после изменения настроек автоматически перестанут работать.

Счётчик увеличивается при каждой загрузке главной страницы. Значение и сессии администратора хранятся в SQLite (`data/visits.sqlite` локально). Для Amvera база и файл настроек находятся в постоянном хранилище `/data`: создайте локальный `admin.config.json` командой настройки и загрузите его в хранилище Amvera как `/data/admin.config.json`. Команда запуска в `amvera.yaml` уже указывает этот путь. Админ-панель не отображается в публичной навигации.

В production запускайте сервер командой `npm start`; сборка клиента выполняется `npm run build`.
