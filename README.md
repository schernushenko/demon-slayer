# Кимэцу — фан-сообщество Demon Slayer

Адаптивная заготовка фан-сайта на React, TypeScript и Vite. Включает главную страницу с баннером на основе `public/demon-slayer.jpg`, карточки персонажей из [Demon Slayer API](https://www.demonslayer-api.com/) с модальными подробностями и hover-анимацией Framer Motion, разделы о мире и дыханиях, прокручиваемый таймлайн сюжетных арок с появлением карточек и параллаксом на GSAP ScrollTrigger и викторину «Кто ты из Клинка?». Цвет акцента карточек соответствует стилю дыхания персонажа. Декоративные элементы и типографика созданы с помощью CSS.

## Запуск

```bash
npm install
npm run dev
```

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

Фанатский проект, не связанный с авторами и правообладателями оригинального произведения.
