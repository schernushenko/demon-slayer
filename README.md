# Кимэцу — фан-сообщество Demon Slayer

Адаптивная заготовка фан-сайта на React, TypeScript и Vite. Включает главную страницу с баннером на основе `public/demon-slayer.jpg`, карточки персонажей из [Demon Slayer API](https://www.demonslayer-api.com/) с модальными подробностями, разделы о мире и дыханиях и подборку сюжетных арок. Декоративные элементы и типографика созданы с помощью CSS.

## Запуск

```bash
npm install
npm run dev
```

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

Фанатский проект, не связанный с авторами и правообладателями оригинального произведения.
